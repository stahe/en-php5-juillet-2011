# Annotated PHP5 Scripts

➡️ Related course: **[Introduction to PHP5 Through Examples](https://stahe.github.io/en-php5-juillet-2011/)**

---

## Overview

This document offers a **collection of PHP5 scripts** covering various areas of the language’s application. It is not a comprehensive course but rather a **compilation of practical examples** intended to illustrate certain features of PHP5 and serve as a basis for experimentation for developers.

The scripts presented are:
- commented directly within the code;
- accompanied by **their console output**;
- sometimes supplemented with **additional explanations** to help better understand how they work.

The goal of this document is to offer a **practical approach to the PHP5 language**, based on the study and analysis of scripts.

---

## Target Audience

This document is intended for developers who have **already used a scripting language**, such as:

- Perl
- Python
- VBScript

It therefore assumes a **certain familiarity with scripting concepts**.

Readers without this prior experience should instead start with a **comprehensive course on PHP** before using this collection of examples.

---

## Reading Method

This document requires **active reading**:

1. Read the script code.
2. Examine the embedded comments.
3. Study the provided execution results.

It is the combination of these three elements that allows you to fully understand each example.
